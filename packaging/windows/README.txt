MeetingClient developer test build
==================================

Target: Windows 10 version 1809 or newer, x64, with a graphics driver
that provides OpenGL 3.3. Fully extract this archive before starting
MeetingClient.exe. Keep the DLLs and the plugin folders beside it.

Enter the shared meeting server address in the New Meeting or Join
Meeting dialog. Both endpoints must be able to reach the meeting
server and the media endpoints it advertises. 127.0.0.1 refers to the
device running the client.

If device access is denied, check Windows privacy settings for camera
and microphone access for desktop apps. For the first call use
headphones, then retest with a speaker to check echo separately.
